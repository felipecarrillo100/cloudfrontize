# Exercise 3.2: The Architect (Viewer Request)

## 🎯 Your Goal

Serve a custom HTML maintenance page directly from the edge PoP.

---

## 🛠 How to Verify Your Work

#### 1. The Browser: What the user sees
1. Visit `http://localhost:3000/`.
2. **Observation**: You see your custom maintenance page. The status code in DevTools is **503**.

#### 2. The Terminal: The sequence
Watch the logs:
```text
[73d6aace] GET / (Host: localhost:3000)
[73d6aace] ├─ ○ [L@E: viewer-request] index.js
[73d6aace] │    [log] [L@E: Architect] Serving Maintenance Page
[73d6aace] ╰─ [Response] Status: 503 [32ms]
```

#### 3. The WebUI: The internal reality
1. Open `http://localhost:3001`.
2. Expand the request in **Real-Time Edge Traffic**. Click the `viewer-request` stage.
3. Click the **BODY** tab at the bottom.
4. **Verification**: You will see the HTML code generated by your function.
