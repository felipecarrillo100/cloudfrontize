    Class HeaderManagerNamespace

    The definitive source of truth for all header lifecycle events in the emulator.

    Backend The HeaderManager centralizes the translation between Node.js, CloudFront Functions (CFF), and Lambda@Edge (L@E) header formats. It is responsible for maintaining "Wire Case" fidelity and enforcing AWS production rules (e.g., forbidden header mutations).

    It primarily uses the Internal Fidelity Format (IFF): Record<string, { key: string; value: string }[]>

    This format ensures that headers like Set-Cookie (multi-value) and original casing (e.g. X-Custom-ID) are preserved regardless of internal JS object normalization.
