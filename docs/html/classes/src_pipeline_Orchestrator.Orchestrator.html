    Class OrchestratorNamespace

    The core orchestration engine for the CloudFrontize pipeline.

    Backend The Orchestrator is the "Brain" of the emulator. It manages the sequential execution of CloudFront Functions (CFF) and Lambda@Edge (L@E) hooks, maintains header state via the HeaderManager, and coordinates origin fetching through various providers.

    It follows a strict "Hook Highway" pattern mimicking the AWS CloudFront request life-cycle.

    See

    • AWS Lambda@Edge
    • AWS CloudFront Functions

    handleRequest

    • handleRequest(
          req: any,
          res: any,
          options: any,
          reqBody?: Buffer<ArrayBufferLike>,
      ): Promise<void>

      The primary entry point for processing an HTTP request through the CloudFront pipeline.

      This method executes the full "Hook Highway":

      1. CFF Viewer Request
      2. L@E Viewer Request
      3. L@E Origin Request
      4. Origin Fetch (S3/Local)
      5. L@E Origin Response
      6. L@E Viewer Response
      7. CFF Viewer Response

      It handles body truncation, short-circuits, and forensic broadcasting.

      Parameters

      • req: any

        The incoming Node.js request object.

      • res: any

        The outgoing Node.js response object.

      • options: any

        Execution options (e.g. strict mode, verbose logging).

      • OptionalreqBody: Buffer<ArrayBufferLike>

        The pre-drained request body Buffer, if any.

      Returns Promise<void>

      A promise that resolves when the response has been fully served.

      Throws

      If no provider is found for the matching origin.
